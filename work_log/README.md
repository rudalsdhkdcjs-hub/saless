# work_log — 작업이력 DB

이 폴더는 모든 작업의 **단일 진실 원천(Single Source of Truth)** 이다.
새 세션은 반드시 이 README와 최신 기록부터 읽고 시작한다.

## 파일명 규칙
```
{YYYYMMDD_HHMMSS}_{유형}_{파일명}.md
```

| 유형 | 의미 |
|---|---|
| 조사 | 외부 자료·법령·수치 검증 |
| 분석 | 모델링·시뮬레이션·결과 해석 |
| 구현 | 코드/도구 작성 |
| 수정 | 기존 산출물 변경 |
| 기획 | 방향·요구사항 정리 |
| 결정 | 확정된 의사결정 기록 |

하나의 작업이 여러 유형이면 `조사+분석+구현` 처럼 `+`로 잇는다.

## 기록 템플릿
각 파일은 `요약 / 입력·가정 / 결과 / 미확정(부족한 정보) / 다음 행동 / 출처` 섹션을 가진다.
도식은 mermaid.
